# WallEye Fund Website

A static website for WallEye Fund, a crypto hedge fund, inspired by Walleye Capital's design.

## Project Structure

```
WallEye_site/
├── index.html          # Homepage
├── about.html          # About Us page
├── approach.html       # Investment Approach page
├── our-people.html     # Our People page
├── our-platform.html  # Our Platform page
├── careers.html        # Careers page
├── contact.html        # Contact page
├── css/
│   └── style.css      # Main stylesheet with animations
├── js/
│   └── main.js        # JavaScript for interactivity
├── images/            # Image assets directory
└── README.md          # This file
```

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern Animations**: Smooth scroll animations, particle effects, and hover interactions
- **Clean UI**: Professional design with dark blue color scheme
- **Interactive Elements**: Mobile menu, form validation, scroll indicators
- **Static Site**: No backend required - pure HTML, CSS, and JavaScript

## Getting Started

1. Open `index.html` in a web browser to view the homepage
2. Navigate through the pages using the header menu
3. All pages are linked and functional

## Pages

- **Homepage** (`index.html`): Hero section with animated particles
- **About** (`about.html`): Company mission, story, and values
- **Approach** (`approach.html`): Investment strategies and methodologies
- **Our People** (`our-people.html`): Team members and leadership
- **Our Platform** (`our-platform.html`): Technology infrastructure
- **Careers** (`careers.html`): Job openings and company culture
- **Contact** (`contact.html`): Contact information and inquiry form

## Customization

- **Colors**: Edit CSS variables in `css/style.css` (root section)
- **Content**: Update HTML files with your content
- **Logo**: Replace the SVG logo in the header of each page
- **Images**: Add images to the `images/` folder and reference them in HTML

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Notes

- This is a static website with no backend functionality
- The contact form shows an alert on submission (no actual email sending)
- All animations and effects are CSS/JavaScript based
- The design is inspired by Walleye Capital's website but adapted for a crypto hedge fund
